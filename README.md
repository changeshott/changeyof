## 🚀 Overview

**Changeyof** is a modern SaaS platform designed to eliminate the tedious process of writing and designing changelogs. It empowers indie hackers, modern developers, and fast-shipping teams to broadcast updates directly to their users through a seamless, high-performance edge network.

No more coding custom "What's New" pages, provisioning databases, or styling UI from scratch. Focus on shipping; we'll handle the announcements.

## ✨ Key Features

- 🤖 **AI-Powered Editor:** Automatically generate beautiful release notes summarizing your latest commits.
- 🌍 **Global Broadcasting:** Instantly push updates to thousands of active users through our high-speed edge network.
- ⚡ **Seamless In-App Sync:** Don't let your updates get lost in social media algorithms. Deliver them directly inside your app where users actually see them.
- 📈 **Engagement Tracking:** Monitor open rates and engagement metrics in real-time.
- 🎨 **Premium Glassmorphism UI:** A stunning, fully interactive dark-to-light scrolling experience built with fluid physics and modern web design principles.

## 🛠️ Tech Stack

This landing page and frontend are built using the modern React ecosystem:

- **Framework:** [Next.js](https://nextjs.org/) (React 18)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) (Spring Physics, Scroll Parallax, Orchestration)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Geist Sans & Geist Mono

## 💻 Getting Started

To run the project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/changeshott/changeyof.git
   cd changeyof
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or yarn install / pnpm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application running.

## 🎨 UI/UX Highlights

- **Interactive 3D Hero Scene:** Hover over floating feature cards that react dynamically to cursor movement using custom tilt physics.
- **Physics-Based Scroll Waves:** Fluid transitions between the dark hero section and the light content section driven by Framer Motion's `useSpring`.
- **Intelligent Staggered Animations:** Elements reveal themselves beautifully as you scroll down the page.
- **Glassmorphism:** Premium frosted-glass effects overlaid on subtle, inverted grids for a high-end SaaS feel.
